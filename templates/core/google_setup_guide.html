Google OAuth Configuration Required

How to enable Google Sign-In on your Shoppin installation

To enable Sign in with Google, you need to register a free OAuth 2.0 Client ID in the Google Cloud Console.

Step-by-step Setup:
  1. Go to the Google Cloud Console → APIs & Services → Credentials.
  2. Click + Create Credentials → OAuth client ID.
  3. Select Web application as Application type.
  4. In Authorized redirect URIs, add:
    {{ redirect_uri }}
  5. Copy your Client ID and Client Secret.
  6. Add them to your project's .env file: 
    GOOGLE_CLIENT_ID=your-google-client-id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=GOCSPX-your-google-client-secret
GOOGLE_OAUTH_REDIRECT_URI={{ redirect_uri }}

Once saved in .env, restarting the dev server will activate one-click Google Sign-In for all users.
